COMMANDS TO START THE APPLICATION LOCALLY:
--------------------------------------------------------------------------------
1. Activate Virtual Environment & Start Server:
   Windows:
     .venv\Scripts\activate
     uvicorn main:app --reload --port 8000

   Direct execution without activating (Windows PowerShell / CMD):
     .venv\Scripts\python -m uvicorn main:app --reload --port 8000

   Linux / macOS:
     source .venv/bin/activate
     uvicorn main:app --reload --port 8000

2. Re-seed Database (if needed):
   Windows:
     .venv\Scripts\python scripts/seeders/seed_atlas.py
   Linux / macOS:
     python scripts/seeders/seed_atlas.py
