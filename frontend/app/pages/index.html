How ATLAS Works: The 12-Stage Lifecycle

ATLAS organizes every step of university thesis and capstone projects from semester kickoff to published graduation grades.

01

Semester & Setup

Coordinators initialize academic sessions, configure team-size bounds, and publish milestone deadlines.

02

Team Formation

Students create teams, invite peers with secure codes, assign a team leader, and ensure single-team constraints.

03

Supervisor Request

Teams send formal supervisor requests. Faculty evaluate proposals and accept or reject with coordinator reassignment fail-safe.

04

Proposal State Machine

Draft → Submitted → Changes Requested → Resubmitted → Approved. Version snapshots preserve history.

05

Milestone Deliverables

SRS, Midterm Reports, Final Code repositories, and documentation submitted against strict server-validated deadlines.

06

Defense Scheduling

Conflict-free defense sessions scheduled with automatic detection of overlapping teams, panel members, or rooms.

07

Rubrics & Evaluation

Coordinator-configured weighted criteria (Methodology, Implementation, Defense) calculated authoritatively on the backend.

08

Grade Publication & Reports

Final grades verified and published by Coordinator; comprehensive CSV export of audits, teams, and academic performance.

Key Features

Engineered For Academic Governance

Beyond simple project tracking — ATLAS provides strict server-side state machines, conflict detection algorithms, and automated rubric calculations.

Multi-Version Proposal Engine

Formal state transitions (Draft → Submitted → Changes Requested → Resubmitted → Approved). Every submission records an immutable version snapshot (v1, v2, v3) preserving feedback history.

Automated Conflict Detection

Server-enforced oral defense scheduling that prevents room collisions, student team schedule clashes, and panel member double-booking across overlapping time slots.

Authoritative Deadline Verification

Late deliverable determination is verified strictly against UTC server timestamps. Eliminates client-side timestamp spoofing for SRS, Midterm, and Final submissions.

Configurable Rubrics & Grading

Custom semester-wide criteria with percentage weights. Evaluators enter raw scores; ATLAS calculates weighted totals and maps directly to institutional letter grades (A+, A, A-).

Non-Bypassable Backend RBAC

Dedicated, isolated workspaces for Students, Supervisors, and Coordinators. URL tampering and direct API calls without proper role tokens are blocked with 403 Forbidden.

One-Click Reports & Audit Logs

Export student rosters, proposal progression, submission records, defense timetables, and final grades directly into CSV format alongside a searchable event audit log.
